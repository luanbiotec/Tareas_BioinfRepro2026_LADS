# Reproducible Bioinformatics — Course Assignments

This repository contains the assignments, exercises, scripts, documentation, and supporting materials developed throughout the Reproducible Bioinformatics course at the University of Chile.

The repository is organized by unit and session to facilitate navigation, track progress, and maintain a structured record of completed activities.

## Objectives

- Organize course assignments and supporting materials.
- Document workflows, commands, and results.
- Practice reproducible research using Bash, Git, and GitHub.
- Maintain version history and document changes.
- Facilitate the review and reproduction of bioinformatics exercises.

## Repository Structure

```text
Tareas_BioinfRepro2026_LADS/
├── README.md
└── Unidad1/
    ├── Sesion1/
    └── Sesion2/
```

Each session directory contains the corresponding assignment files, scripts, documentation, and supporting evidence, where applicable.

## Reproducibility

This repository uses Git and GitHub for version control. Instructions and commands are documented whenever appropriate to support the review and reproduction of the exercises.
